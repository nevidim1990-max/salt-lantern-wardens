Смотрители Соляных Маяков (Salt Lantern Wardens)
================================================

Полный статический проект. Запускается в браузере без серверной части, Node.js или сборки.
Все необходимые скрипты, данные и изображения лежат отдельными файлами в этой папке.

КАК ЗАПУСТИТЬ:
1. Распакуйте salt-lantern-wardens.zip целиком.
2. Откройте salt-lantern-wardens/index.html в Chrome, Edge или Firefox.
3. Не переносите index.html отдельно: рядом должны оставаться скрипты и папки assets/ и data/.

Для публикации загрузите всю папку проекта на статический хостинг или игровой портал, сохранив структуру файлов.

СТРУКТУРА:
- index.html       — точка входа и игровой интерфейс
- phaser.min.js    — локальная копия Phaser 3
- game_data.js     — данные игры и манифест изображений
- runtime-data.js  — адаптер исходных данных к игровому формату
- assets/          — 109 PNG-изображений и спрайтов
- data/            — исходные JSON-контракты и данные
- README.txt       — эта инструкция

Жанр: Tower Defense (track_lane)
Тема: Смотрители Соляных Маяков
